# 2xu-follow

2XU 테크스토리 · 팔로워 이벤트 정적 페이지.

클라이언트 공유는 **목업 뷰어 하나**만 전달합니다.

## 저장소

https://github.com/richosj/2xu-follow

## GitHub Pages

목업 뷰어: **https://richosj.github.io/2xu-follow/**

1. GitHub 저장소 **Settings → Pages** 로 이동합니다.
2. **Build and deployment** 의 **Source** 를 **GitHub Actions** 로 선택합니다.
3. `main` 에 푸시되면 `.github/workflows/pages.yml` 이 사이트를 배포합니다.

## 페이지

| 파일 | 용도 |
| --- | --- |
| `index.html` | 클라이언트 목업 뷰어 (모바일 / 태블릿 / PC, 크게보기) |
| `tech.html` | 테크스토리 (PC / 모바일 반응형) |
| `follow.html` | 팔로워 전용 이벤트 (PC / 모바일 반응형) |

Figma에서 보낸 에셋은 `images/tech/`, `images/follow/` 에 둡니다.
