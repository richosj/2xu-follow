# 2xu-follow

2XU SEASON OFF 프로모션 정적 페이지 (`index.html`, `base.css`, `style.css`).

## 저장소

https://github.com/richosj/2xu-follow

## GitHub Pages

배포 주소: **https://richosj.github.io/2xu-follow/**

1. GitHub 저장소 **Settings → Pages** 로 이동합니다.
2. **Build and deployment** 의 **Source** 를 **GitHub Actions** 로 선택합니다.
3. `main` 에 푸시되면 `.github/workflows/pages.yml` 이 사이트를 배포합니다. (Actions 탭에서 실행 로그 확인)

최초 한 번만 Source 를 GitHub Actions 로 바꾸면 이후 푸시마다 자동 배포됩니다.
